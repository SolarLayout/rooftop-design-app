## What to set

Choose the module the site buys.

1. Press `Change` on the module's card to open `Choose a module`, the app's library.
2. Search by maker, model, file name or power, or press `Filter` to narrow the list by `Power`.
3. Choose a row, then press `Use this module`. For a module the library does not hold, drop its module file (PAN) under the list, or press `Choose a file`; on a phone, press `Choose your own module file (PAN)`.

The card shows the model, the maker, the rated power and the size. `Details` opens the electrical figures: `Open-circuit voltage (Voc)`, `Short-circuit current (Isc)`, `Bifacial, rear gain` for a bifacial module, and the `Voc coefficient`, how much the voltage rises as the module gets colder.

The section says `Default` for the app's module, and `Yours` once another is read.

## What it changes

A new module lays out the roof again, then the design runs again.

- Its size, with the <HelpLink k="studio.section.mounting">mounting</HelpLink>, sets the footprint of each position, and so how many fit.
- Its Voc, its temperature coefficients and its own highest voltage set how many modules a string holds.
- Its currents, Imp and Isc, set how many strings an MPPT takes.
- Its rated power sets the system's size in kWp, the DC/AC ratio of each option and the energy.

## When to change it

When the site uses another module, or the client asks to compare two. An exclamation mark under the card says what to check: a Voc coefficient outside the usual range, or a file that gives no size of the module. For the first, enter the datasheet's coefficient under `Sizing temperatures` in the Strings step. For the second, choose a file that has the size. A file that cannot be read leaves the module as it was and says why.
