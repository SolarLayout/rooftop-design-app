Choose a module or an inverter

Replace on the module card and on the inverter card opens a picker over the app's own library of PVsyst files. A search over the maker, the model and the file's name, and range sliders to narrow the list: the module by its power, the inverter by its AC power and its count of MPPT. The list is sorted by power. A row is chosen, then used; the file is read by the engine as a dropped file is, so the card, the layout and the energy follow as they do today. A file of one's own is still taken, under the list. Phone 390: the dialog's bottom sheet, at its full height. The actions under each other: Use this module, then the file of one's own; the handle closes.

The module: the bottom sheet at its full height; the row in three lines; the order a select beside the count (Power, Efficiency, Bifaciality, Model, each both ways)
