Where the picker opens

The picker opens from the two cards that hold the equipment: the module card of the Array lens and the inverter card of the Strings lens. Their button Replace, which opened the file drop, becomes Change, in the same place, and opens the picker; the file of one's own is in the picker. After a choice the card is the new module or inverter, as a file read makes it today, and under it the file's name says “From the app” when it came from the library.
