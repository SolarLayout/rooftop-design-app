Before a system voltage there are no options and no energy: the page shows the API's title and message of no_options (D37), “Choose a system voltage to size the strings”, “600, 1000 or 1500 V. Nothing is sized until you choose.”, on the note surface with the accent line and halo of a decision, and a button to the Strings lens, where the voltage is chosen. No voltage is offered here: the choice is made once, in the Strings lens, and never preselected.

The header keeps the weather select and says what is ready: the positions of the layout, 790, and the weather's hours, temperatures and horizon. There is no option switch, no KPI, no chain, no chart and no summary: a value that cannot exist yet is absent with its reason, never 0. The assumptions stay, as fields: they are inputs and can be set before the voltage.

The same page serves the other reasons of no_options (no positions, no string length that fits, too few positions), each in the API's words.

The first load: no value was ever there, so every place of a value holds a skeleton (components.md “Skeleton”): the line under the title a bar of 12, the lead tile a label of 10 and a value of 22, the P cells on surface-2 their blocks in control-active, the six tiles a label of 10 and a value of 18. They breathe over 1.6 s and stand still under reduced motion.

Under the title the ring of 20 with its arc, “Opening Pune demo roof”, and the step of the engine, “Fitting modules on the roof”. The weather select stands as it is; the option switch is dimmed until the options come.

No skeleton ever replaces a value that was there: a value of before stays, dimmed (the next card).

A run that failed keeps the last good values, not dimmed, and says so under the title in a note: “Energy was not updated”, “Values are of the design before · Try again”, Try again a quiet press that runs again. Under them the reason in the API's words, so that what to do is clear.

The message here is the API's for a design whose document holds no weather for its site: “This project has no weather for 18.5200, 73.8600 yet. Load the PVGIS TMY weather first.” In the running app this refusal is answered by loading the weather and running again (decision 11); any other failure stands here in the same words the API gives.

The notes drawer of the shell lists the same note; the page says it where the value is.
