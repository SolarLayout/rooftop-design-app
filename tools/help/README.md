# tools/help

The generator of the in-app help's manifest (`bun help:gen`) and its gates (`bun test tools/help`): links, aliases, a
section's options against the code (`options.ts`), numbers typed with a unit, the manifest fresh, and every section heading
of an input panel with its ? (`coverage.ts`).

How to write a topic and what each message of the gate asks: [`docs/help-content.md`](../../docs/help-content.md).
